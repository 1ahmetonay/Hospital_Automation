# Proje Veritabanı Tabloları

Bu projede kullanılan veritabanı tabloları ve alanları aşağıda listelenmiştir:

## Branslar
- **Bransİd**: Bransın benzersiz kimliği
- **BransAd**: Bransın adı

## Doktorlar
- **Doktorİd**: Doktorun benzersiz kimliği
- **DoktorAd**: Doktorun adı
- **DoktorSoyad**: Doktorun soyadı
- **DoktorBrans**: Doktorun bransı
- **DoktorTC**: Doktorun T.C. kimlik numarası
- **DoktorSifre**: Doktorun şifresi

## Duyurular
- **DuyuruId**: Duyurunun benzersiz kimliği
- **Duyuru**: Duyurunun metni

## Hastalar
- **Hastaİd**: Hastanın benzersiz kimliği
- **HastaAd**: Hastanın adı
- **HastaSoyad**: Hastanın soyadı
- **HastaTC**: Hastanın T.C. kimlik numarası
- **HastaTelefon**: Hastanın telefon numarası
- **HastaSifre**: Hastanın şifresi
- **HastaCinsiyet**: Hastanın cinsiyeti

## Randevular
- **Randevuİd**: Randevunun benzersiz kimliği
- **RandevuTarihi**: Randevu tarihi
- **RandevuSaat**: Randevu saati
- **RandevuBrans**: Randevu bransı
- **RandevuDoktor**: Randevu doktoru
- **RandevuDurum**: Randevu durumu
- **HastaTC**: Hastanın T.C. kimlik numarası
- **HastaSikayet**: Hastanın şikayeti

## Sekreterler
- **SekreterAdSoyad**: Sekreterin adı ve soyadı
- **SekreterTC**: Sekreterin T.C. kimlik numarası
- **SekreterSifre**: Sekreterin şifresi
